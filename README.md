# COVID-19 Global Data Analysis

An exploratory data analysis (EDA) project examining global COVID-19 trends, case distributions, and country-wise statistics using Python.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/shivangitarawat/covid-19-data-analysis/blob/main/Covid19.ipynb)

## Overview
This notebook cleans, explores, and visualizes global COVID-19 records across countries and regions, tracking confirmed cases, recoveries, deaths, and active cases over time.

## Dataset
- **Source file:** `Covid_19_Clean_Complete.csv`
- **Size:** 49,068 rows × 10 columns
- **Key Features:** `Province/State`, `Country/Region`, `Lat`, `Long`, `Date`, `Confirmed`, `Deaths`, `Recovered`, `Active`, `WHO Region`

## Tech Stack & Libraries
- **Python 3**
- **Pandas & NumPy** — Data loading, cleaning, grouping, and aggregation
- **Matplotlib & Seaborn** — Trend plots, country comparisons, and visual insights
